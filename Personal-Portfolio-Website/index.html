Classification Problem Solution

Problem Statement: Consider a classification problem with two binary features, \(x_1, x_2 \in \{0, 1\}\). Suppose \(P(Y = y) = 1/32\), \(P(x_1 = 1 | Y = y) = y/46\), \(P(x_2 = 1 | Y = y) = y/62\). Which class will naive Bayes classifier produce on a test item with \(x_1 = 1\) and \(x_2 = 0\)?

1. Naive Bayes Objective

The Naive Bayes classifier selects the class \(y\) that maximizes the posterior probability, which is proportional to the joint probability:

\[\hat{y} = \arg\max_y P(Y = y, x_1 = 1, x_2 = 0)\]

Assuming features are independent given the class (Naive Bayes assumption):

\[P(Y = y, x_1 = 1, x_2 = 0) = P(Y = y) \cdot P(x_1 = 1 \mid Y = y) \cdot P(x_2 = 0 \mid Y = y)\]

2. Given Information

  • Prior: \(P(Y = y) = \frac{1}{32}\)
  • Likelihood 1: \(P(x_1 = 1 \mid Y = y) = \frac{y}{46}\)
  • Likelihood 2: \(P(x_2 = 1 \mid Y = y) = \frac{y}{62}\)
  • Complement for Likelihood 2: \(P(x_2 = 0 \mid Y = y) = 1 - \frac{y}{62}\)

3. Function Formulation

Substitute these into the joint probability equation \(f(y)\):

\[f(y) = \frac{1}{32} \cdot \frac{y}{46} \cdot \left(1 - \frac{y}{62}\right)\]

To maximize \(f(y)\), we can ignore the constant factors \(\frac{1}{32}\) and \(\frac{1}{46}\) and maximize:

\[g(y) = y \left(1 - \frac{y}{62}\right) = y - \frac{y^2}{62}\]

4. Optimization Steps

Take the derivative of \(g(y)\) with respect to \(y\) and set it to zero:

\[g'(y) = 1 - \frac{2y}{62} = 1 - \frac{y}{31}\]

Solving for \(y\):

\[1 - \frac{y}{31} = 0 \implies y = 31\]

Since the second derivative \(g''(y) = -\frac{1}{31}\) is negative, \(y = 31\) is a point of maximum.

5. Numerical Verification

Comparing \(g(y)\) values near the optimum:

  • For \(y = 30\): \(30 \cdot (1 - 30/62) \approx 15.483\)
  • For \(y = 31\): \(31 \cdot (1 - 31/62) = \mathbf{15.5}\)
  • For \(y = 32\): \(32 \cdot (1 - 32/62) \approx 15.483\)

The maximum occurs precisely at \(y=31\).

Conclusion: The classifier will produce class 31.
Correct Option: c) 31
