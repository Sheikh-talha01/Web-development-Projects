1.4 Underfitting and Capacity

Question Statement: You train a network on 20 samples. Training converges, but training loss is very high. You then train on 10,000 samples. Is your approach to fixing the problem correct? If not, give a solution.

Step 1 Diagnosis of Training Behavior
A high training loss at convergence indicates that the model is failing to learn the training data itself. This is the definition of High Bias (Underfitting).

Step 2 Analyzing the Effect of Data Volume
Underfitting occurs when the model's complexity (capacity) is lower than the complexity of the data's underlying patterns. If the model cannot fit a small set of 20 samples, increasing the data volume to 10,000 samples will not fix the structural inability of the model to learn. In fact, it often increases the training error as the model now has to fail at fitting many more points.

Correct Strategy: Increasing Model Capacity
Instead of adding more data, you must make the model "smarter" or more complex:
  • Add more layers (Depth).
  • Add more hidden units/neurons (Width).
  • Reduce regularization (e.g., lower dropout or weight decay).
  • Increase training time (epochs) if convergence was actually an illusion.

2.1 Naive Bayes Numerical Derivation

Question Statement: Given \(P(Y = y) = 1/32\), \(P(x_1 = 1 | Y = y) = y/46\), \(P(x_2 = 1 | Y = y) = y/62\). For a test item with \(x_1 = 1\) and \(x_2 = 0\), which class will be produced?

Full Derivation:

Step 1 Naive Bayes Objective Function
We choose \(y\) to maximize the joint probability:

\[P(Y=y, x_1=1, x_2=0) = P(Y=y) \cdot P(x_1=1|Y=y) \cdot P(x_2=0|Y=y)\]

Step 2 Identify Conditional Probabilities
Note that \(P(x_2=0|Y=y) = 1 - P(x_2=1|Y=y)\). Therefore:

\[P(x_1=1|Y=y) = \frac{y}{46}\] \[P(x_2=0|Y=y) = 1 - \frac{y}{62} = \frac{62 - y}{62}\]

Step 3 Substitute into Objective Function
Substitute the given values into the product:

\[f(y) = \frac{1}{32} \cdot \frac{y}{46} \cdot \frac{62 - y}{62}\]

Step 4 Simplication for Optimization
Since \(\frac{1}{32 \cdot 46 \cdot 62}\) is a constant positive factor, we only need to maximize the numerator:

\[g(y) = y \cdot (62 - y) = 62y - y^2\]

Step 5 Finding the Maximum (Algebraic Method)
The function is a downward parabola with roots at \(y=0\) and \(y=62\). The vertex (maximum point) is always at the midpoint of the roots:

\[y_{max} = \frac{0 + 62}{2} = 31\]
Final Answer: 31 (Option c)

2.2 Decision Boundary Numerical Plotting

Question Statement: Decision rule: Predict \(Y=1\) if \(3X_1 + 5X_2 - 15 \ge 0\). Plot the boundary and regions.

Full Calculation:

Step 1 Define the Line
The boundary occurs at the threshold where the inequality becomes an equality:

\[3X_1 + 5X_2 - 15 = 0\]

Step 2 Find \(X_1\)-axis Intercept
Set \(X_2 = 0\):

\[3X_1 + 5(0) - 15 = 0\] \[3X_1 = 15 \implies X_1 = 5\] \[\mathbf{Point \ 1: (5, 0)}\]

Step 3 Find \(X_2\)-axis Intercept
Set \(X_1 = 0\):

\[3(0) + 5X_2 - 15 = 0\] \[5X_2 = 15 \implies X_2 = 3\] \[\mathbf{Point \ 2: (0, 3)}\]

Step 4 Region Classification Test
Test origin \((0,0)\): \(3(0) + 5(0) - 15 = -15\). Since \(-15 < 0\), the region containing the origin is \(Y=0\). The opposite side is \(Y=1\).

3.1 & 3.2 Conceptual Quiz

Q3.1: Which is FALSE about decision trees?
  • (a) Don't require separate training phase.
  • (b) Depth increases variance/overfitting.
  • (c) Shallow trees have high variance and low bias. (FALSE)
  • (d) Recursive splitting reduces impurity.

Explanation: Shallow trees are simplified models. They have Low Variance (they don't change much with different data) and High Bias (they are too simple to fit reality).

Q3.2: Distinguish classification vs regression trees.
  • (b) Classification uses categorical labels (Gini/Impurity), Regression uses continuous values (Variance/MSE).

Why (c) is wrong? Regression trees can output any real number (continuous), not just binary values. The term "binary continuous" is an oxymoron.

3.3 Regression Tree Complete Derivation

Question Statement: Predict Price using Size \(\le\) 1800 or Floors \(\le\) 2. Calculate Reduction in Variance.

Step 1: Calculate Root Mean (\(\mu\)) and Root Variance (\(\sigma^2\))

Data: \(P = \{120, 130, 150, 160, 180, 300\}\), \(n=6\)

\[\mu_{Root} = \frac{120+130+150+160+180+300}{6} = \frac{1040}{6} = \mathbf{173.33}\] \[\sigma^2_{Root} = \frac{(120-173.3)^2 + (130-173.3)^2 + (150-173.3)^2 + (160-173.3)^2 + (180-173.3)^2 + (300-173.3)^2}{6}\] \[\sigma^2_{Root} = \frac{2844.44 + 1877.78 + 544.44 + 177.78 + 44.44 + 16044.44}{6} = \frac{21533.34}{6} = \mathbf{3588.89}\]

Step 2: Evaluate Split A (Size \(\le\) 1800)

Left Node (Size \(\le\) 1800): {120, 130, 150, 160}, \(n_L=4\)

\[\mu_L = \frac{560}{4} = 140\] \[\sigma^2_L = \frac{(120-140)^2 + (130-140)^2 + (150-140)^2 + (160-140)^2}{4} = \frac{400+100+100+400}{4} = \mathbf{250}\]

Right Node (Size > 1800): {180, 300}, \(n_R=2\)

\[\mu_R = \frac{480}{2} = 240\] \[\sigma^2_R = \frac{(180-240)^2 + (300-240)^2}{2} = \frac{3600+3600}{2} = \mathbf{3600}\]

Split A Summary:

Weighted Variance = \(\frac{4}{6}(250) + \frac{2}{6}(3600) = 166.67 + 1200 = 1366.67\)
Variance Reduction (A) = \(3588.89 - 1366.67 = \mathbf{2222.22}\)

Step 3: Evaluate Split B (Floors \(\le\) 2)

Left Node (Floors \(\le\) 2): {120, 150, 160, 300}, \(n_L=4\)

\(\mu_L = \frac{120+150+160+300}{4} = \frac{730}{4} = \mathbf{182.5}\)
\(\sigma^2_L = \frac{(120-182.5)^2 + (150-182.5)^2 + (160-182.5)^2 + (300-182.5)^2}{4} = \frac{3906.25 + 1056.25 + 506.25 + 13806.25}{4} = \mathbf{4818.75}\)

Right Node (Floors > 2): {130, 180}, \(n_R=2\)

\(\mu_R = \frac{130+180}{2} = \mathbf{155}\)
\(\sigma^2_R = \frac{(130-155)^2 + (180-155)^2}{2} = \frac{625+625}{2} = \mathbf{625}\)

Split B Summary:

Weighted Variance = \(\frac{4}{6}(4818.75) + \frac{2}{6}(625) = 3212.5 + 208.33 = 3420.83\)
Variance Reduction (B) = \(3588.89 - 3420.83 = \mathbf{168.06}\)
Best Split: Size \(\le\) 1800 (VR = 2222.22)
